# 웰만다 (WELLMANDA) · 30일 자기관리 PWA

## 실행

```bash
npm install
npm start
```

`http://localhost:3000` 접속. HTTPS로 배포하면 갤럭시 Chrome / 아이폰 Safari에서 홈 화면에 설치할 수 있습니다.

## Render 배포

GitHub에 이 폴더 **안의 파일들**을 업로드하세요. 별도 폴더로 업로드했다면 Render `Root Directory`를 해당 폴더명으로 지정합니다.

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- VAPID 키 **불필요**: 서버 푸시를 사용하지 않습니다.

## 기능

- 성인 설문: 키·체중·나이·선택 성별, 식사 가능 여부, 헬스장 이용, 운동 경험, 운동 제한
- 헬스장 머신 운동 또는 걷기·집운동 추천
- 30일 개인 체크 기록과 100점 평가
- 하루·주간·30일 A4 1장 리포트 (브라우저 인쇄에서 PDF 저장)
- CSV 내보내기, JSON 백업·복원
- 30일 개인 캘린더 알림(.ics) 내보내기
- 사용자 기록은 브라우저 localStorage에만 저장; 서버 API로 전송하지 않음

## 한계 및 주의

- `.ics` 캘린더 파일의 반복 알림은 캘린더 앱에 사용자가 직접 가져오고 권한을 허용해야 합니다. PWA 자체는 앱이 닫힌 상태에서 서버 없는 정시 푸시를 보장하지 않습니다.
- 서버에는 기본적인 웹 접속 로그(IP, 접속 시각 등)가 남을 수 있습니다. 건강 기록은 요청하지 않으며 외부 분석 도구도 포함하지 않습니다.
- 브라우저 데이터 삭제 또는 기기 교체 시 기록이 없어질 수 있습니다. JSON 백업 권장.
- 체중 변화량은 점수에 직접 반영하지 않습니다. 의료적 진단/치료용이 아닙니다.
- 병원 실제 배포 전에 개인정보 처리 고지, 보안, 접근성, 임상적 적합성 점검이 필요합니다.
- 이 버전은 계정/환자 관리자/서버 기록/문자 발송/푸시 알림을 제공하지 않습니다.
