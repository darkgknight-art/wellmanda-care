# 웰만다 WELLMANDA — 30일 개인 건강습관 PWA v3

## 주요 기능
- 3단계 환자 자기관리 설문: 기본정보 → 식사/운동 환경 → 안전 확인
- 헬스장 이용/미이용, 운동 경험, 통증 여부에 따른 보수적인 운동 안내
- 30일 식사/운동/수면/수분/체중/한 줄 회고 기록
- 하루·주간·30일 100점 실천 리포트, A4 인쇄/PDF, CSV 및 JSON 백업/복원
- 7일 점수 추이, 실천 연속일, 30일 진행률
- 로컬 브라우저 저장. 건강 기록 서버 전송/계정/전화번호 수집 없음
- 개인별 .ics 캘린더 일정 내보내기 (휴대폰에서 일정 가져오기 필요)
- W + 점 아이콘 유지, 갤럭시/아이폰 PWA 설치 지원

## 배포
압축파일에는 `wellmanda-app` 폴더가 포함되어 있습니다. GitHub에 이 폴더째 업로드했다면 Render **Root Directory**는 `wellmanda-app` 입니다. 해당 폴더 안의 파일을 저장소 최상위에 업로드했다면 Root Directory를 비워 두세요.

Render Web Service: Node / Build `npm install` / Start `npm start` / HTTPS 자동 제공.

## 중요한 제한사항
- 건강기록은 `localStorage`에만 저장됩니다. 브라우저 데이터 삭제/기기 변경 시 사라질 수 있어 백업을 권장합니다.
- Render에는 정적 웹 리소스 요청만 전달됩니다. 현재 버전은 건강 기록 수집 API, 사용자 계정, 분석 도구, 외부 추적 스크립트를 포함하지 않습니다.
- 로컬 저장만으로 개인정보보호 의무가 완전히 사라지는 것은 아닙니다. 병원 실제 배포 전 보안/법률/의료 검토가 필요합니다.
- PWA에서 앱을 닫은 상태의 정시 로컬 알림을 보장하지 않으므로 `.ics` 캘린더 파일을 제공합니다. 캘린더 가져오기와 알림 허용은 기기별로 필요합니다.
- 점수는 실천 점수이며 의료적 성과/치료 효과가 아닙니다. 미기록일은 평균에서 제외되고 기록일수는 별도 표시됩니다.
- 성인 생활습관 교육용 파일럿입니다. 임신, 통증, 만성질환, 운동 제한이 있다면 의료진과 상의하세요.

## 업데이트
앱의 저장 키를 이전 버전과 동일하게 유지하여 동일한 origin(주소)에서 재배포할 경우 기존 로컬 기록을 계속 읽습니다. 새 주소로 배포하면 별도 저장소이므로 JSON 백업/복원을 사용하세요.

- 설문·로컬 저장·백업·리포트 기존 기능 유지
- 서버 푸시 미포함: 앱 종료 후 알림은 캘린더 앱 설정에 의존


## V5: 행동 중심 코치
- 오늘의 운동/식사/취침 항목을 누르면 단계별 상세 안내가 열립니다.
- 운동 완료 시 다음 미완료 일정으로 이동할 수 있는 카드가 나타납니다.
- '10분 뒤 다시 보기'는 앱이 열려 있는 동안만 동작하며 백그라운드 알림이 아닙니다.
- 휴대폰 캘린더(.ics) 내보내기는 30일간 일정과 운동 세부내용을 포함합니다.
- 건강 설문과 실천 여부는 기존과 동일하게 로컬 저장됩니다.


## V6: 전부 체크 + 목표 달성률(%)
- 홈의 체크리스트에서 식사·운동·물·(주 1회)체중·한 줄 돌아보기·취침을 모두 한 번에 체크합니다. 운동도 줄의 ○ 버튼으로 바로 체크됩니다.
- 체크할 때마다 "목표 N% → M%" 피드백이 표시되고, 홈에 30일 목표 달성률·지금까지 이행률·남은 할 일 개수가 보입니다.
- 30일 목표 = 체크리스트 전체 체크(100%). 체크하지 않은 날은 0%로 계산됩니다.
- 30일 체크 현황 칩을 눌러 지난 날짜도 체크할 수 있습니다.
- 체중을 입력하면 희망 체중까지의 진행률(%)을 참고용으로 표시합니다. 의료적 성과가 아닙니다.
- 수정: 첫날 날짜에 홈이 고정되던 문제 해결 (홈은 항상 오늘 기준).
- 기존 저장 키 유지: 같은 주소로 재배포하면 이전 기록을 그대로 읽습니다.
